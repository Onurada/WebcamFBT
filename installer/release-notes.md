**WebcamFBT** — full body tracking for SteamVR from a webcam. / Webcam ile SteamVR için full body tracking.

**Kurulum / Install:** download `WebcamFBT-Setup-*.exe` and run it. No Python or .NET needed; installs for the current user (no administrator rights). Close SteamVR first so the driver can be registered.
`WebcamFBT-Setup-*.exe` dosyasını indirip çalıştır. Python ya da .NET gerekmez; yönetici izni istemeden kullanıcıya kurulur. Sürücünün kaydedilebilmesi için önce SteamVR'ı kapat.

Windows may show a SmartScreen warning because the installer is not code-signed: *More info → Run anyway*.
Kurulum dosyası imzalı olmadığı için Windows SmartScreen uyarısı çıkabilir: *Ek bilgi → Yine de çalıştır*.

See README.md (English) / KULLANIM.md (Türkçe) in the install folder.
